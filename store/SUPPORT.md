## FAQ

**The voice coach is silent / Stemmeguiden er tavs**
Check that the phone is not in silent mode and that "Voice guide" is not set to Off in Settings. Use "Sound test" before starting a run.
Tjek at telefonen ikke er på lydløs, og at "Stemmeguide" ikke står på Fra i Indstillinger. Brug "Lydtest" før du starter.

**No distance outdoors / Ingen distance udendørs**
Allow location access for Runstart in the iPhone's Settings → Privacy → Location Services. GPS is only used for outdoor runs.
Giv Runstart adgang til placering i iPhonens Indstillinger → Anonymitet → Lokalitetstjenester. GPS bruges kun ved udendørs løb.

**Treadmill distance / Distance fra løbebåndet**
After a treadmill run you can type in the distance from the treadmill display on the summary screen. It counts towards your total and your milestones.
Efter et løbepas på løbebånd kan du skrive distancen fra løbebåndet ind. Den tæller med i din samlede distance og dine milepæle.

**Change language / Skift sprog**
Tap the flag in the top-right corner. Text and voice can each have their own language.
Tryk på flaget øverst til højre. Tekst og tale kan have hvert sit sprog.

**Move to a new phone / Ny telefon**
Settings → Your data → Export backup, then Import backup on the new phone.
Indstillinger → Dine data → Eksportér backup, og derefter Importér backup på den nye telefon.
